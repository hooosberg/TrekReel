Custom Data Sources / 自定义数据源

本页面用于说明高级数据源的手动添加方式。 以下商用或受限源已从默认选项移除，仅供用户自行评估与手动配置。

⚠️ 版权与许可提醒：请在使用前确认对应数据源的商业授权、归属声明和使用限制。

How To Add / 添加方法

  1. 打开 App：设置 → 数据源。
  2. 选择卫星影像中的“自定义瓦片源”。
  3. 粘贴 URL 模板并保存应用。
  4. 如服务方要求 Key 或签名，请按其官方文档配置。

Template Placeholders / URL 占位符

  • {z}：缩放级别
  • {x}：瓦片 X 坐标
  • {y}：瓦片 Y 坐标
  • {quadkey}：Bing 专用编码
