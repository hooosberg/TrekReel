<h2 id="english">🌍 English</h2>

### About

**TrekReel** is a local-first 3D storytelling app built for hikers, runners, and cyclists. Import GPX tracks and create cinematic route videos instantly — no cloud required.

### ✨ Features

| Feature | Description |
|---------|-------------|
| **📥 Import Tracks** | Drag & drop GPX, KML, GeoJSON, or FIT files |
| **🏔️ 3D Terrain** | Real elevation data with satellite/outdoor map overlays |
| **🎬 Cinematic Camera** | Smooth camera interpolation with keyframe system |
| **📍 Rich Annotations** | Add markers, photos, and notes at key spots |
| **🎥 Video Export** | Generate route movies in multiple resolutions |
| **🔒 Privacy First** | All data stays on your device, offline-ready |

### 🚀 Quick Start

1. **Import Track** — Click "Import" or drag GPX/KML/GeoJSON files
2. **Choose Style** — Switch map layers (Satellite/Outdoor/Dark) and adjust lighting
3. **Set Camera** — Add keyframes at summits, camps, and key spots
4. **Add Markers** — Double-click to add POI markers with photos or text
5. **Export** — Press Space to preview, then click "Export Video"

<h2 id="中文">🇨🇳 中文</h2>

### 关于

**途影 (TrekReel)** 是一款本地优先的 3D 故事制作应用，专为徒步、越野、骑行爱好者设计。导入 GPX 轨迹，一键生成电影级路线动画——无需云端，隐私优先。

### ✨ 功能特点

| 功能 | 说明 |
|------|------|
| **📥 导入轨迹** | 支持拖拽导入 GPX、KML、GeoJSON、FIT 文件 |
| **🏔️ 3D 地形** | 基于真实高程数据，支持卫星图/户外图叠加 |
| **🎬 电影级运镜** | 平滑的相机运动插值，关键帧系统 |
| **📍 丰富标注** | 在关键位置添加标记、照片和注释 |
| **🎥 视频导出** | 支持多种分辨率导出路线视频 |
| **🔒 隐私优先** | 数据仅保存在本地，支持离线使用 |

### 🚀 快速入门

1. **导入轨迹** — 点击「导入」或拖入 GPX/KML/GeoJSON 文件
2. **选择风格** — 切换地图图层（卫星图/户外图/暗色模式），调整光照
3. **设定运镜** — 在山顶、营地等关键位置添加关键帧
4. **添加标记** — 双击路线添加 POI 标记，上传照片或文字
5. **预览导出** — 按空格键预览，点击「导出视频」生成路书
