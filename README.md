# TrekReel (途影) — 3D Trail, Terrain Video & 3D-Print Studio

Turn GPX / KML / KMZ routes into cinema-grade 3D terrain videos, ultra-HD route posters, free monochrome 3D-printable STL reliefs, and full-color OBJ terrain models — 100% locally on your computer with offline global terrain and basemap bundles.

## Download

### macOS (Apple Silicon)
Install directly from the **Mac App Store**:
- https://apps.apple.com/us/app/trekreel-3d-map-video-maker/id6758914035?mt=12

macOS Pro upgrades are handled natively through Apple StoreKit In-App Purchase.

### Windows 10 / 11 (x64 Standalone Edition)
Download the latest Windows installer from GitHub Releases:
- **Direct Installer (`TrekReel-Setup-1.0.6-x64.exe`):** https://github.com/hooosberg/TrekReel/releases/latest/download/TrekReel-Setup-1.0.6-x64.exe
- **All Releases & Checksums (`SHA256SUMS.txt`):** https://github.com/hooosberg/TrekReel/releases

> **Windows SmartScreen Notice**
> The standalone `.exe` installer is currently unsigned while Windows distribution rolls out. If Windows Defender SmartScreen shows **"Windows protected your PC"**, click **More info** → **Run anyway**, and verify the file SHA-256 against `SHA256SUMS.txt` attached to the release.
> Full walkthrough: https://trekreel.hooosberg.com/guide#windows-install
