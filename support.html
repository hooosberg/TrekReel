Support & Guide

Whether you're just starting out or looking for advanced tips, find everything here.

🚀 快速入门：5步制作你的路线故事

1

导入轨迹

点击左上角「导入」按钮或直接拖入 GPX/KML/GeoJSON 文件。途影会自动识别并在 3D 地图中加载你的路线。

2

选择风格

在右侧面板切换地图图层（卫星图/户外图/暗色模式），并调整光照与天空气氛，设定故事基调。

3

设定运镜

使用鼠标或快捷键浏览地图。在关键位置（如山顶、营地）点击「添加关键帧」，创建平滑的相机运动路径。

4

添加标记

双击路线任意位置添加 POI 标记，上传照片或输入文字，通过标注丰富故事细节。

5

预览导出

按下空格键预览动画。满意后点击顶部「导出视频」，选择分辨率与帧率，生成你的路书视频。

🚀 Quick Start: Create Your Story in 5 Steps

1

Import Track

Click "Import" or drag & drop GPX/KML/GeoJSON files. TrekReel automatically visualizes your route in 3D.

2

Choose Style

Switch map layers (Satellite/Outdoor/Dark) and adjust lighting/atmosphere to set the tone.

3

Set Camera

Navigate the map. Click "Add Keyframe" at key spots (summits, camps) to create smooth camera paths.

4

Add Markers

Double-click the route to add POI markers. Upload photos or text to enrich details.

5

Export

Press Space to preview. Click "Export Video" to generate your route movie.

❓ 常见问题

为什么导出视频失败？

请确保您的项目至少包含 2 个关键帧以形成动画。另外，请检查导出路径是否有写入权限。

如何加载自定义地图源？

访问 自定义数据源 页面查看支持的格式。你需要 TileJSON 或 XYZ URL。

支持哪些轨迹文件格式？

目前完美支持标准的 GPX、KML、GeoJSON 和 FIT 文件。

如果应用窗口找不到了怎么办？

点击 Dock 栏图标或使用菜单栏 Window -> Show Main Window 即可找回。

❓ FAQ

Why did video export fail?

Ensure your project has at least 2 keyframes. Also verify write permissions for the destination folder.

How to add custom map sources?

Visit the Custom Sources page. You need a valid TileJSON or XYZ URL.

Supported file formats?

Standard GPX, KML, GeoJSON, and FIT files are fully supported.

Window disappeared?

Click the Dock icon or use menu Window -> Show Main Window.

🌍 自定义数据源

高级功能：如何添加第三方瓦片服务

⚠️ 版权提醒： 请确保您拥中所添加数据源的商业授权或使用许可。

如何添加

  1. 打开 App 设置 → 数据源
  2. 在卫星影像下方选择 自定义瓦片源
  3. 粘贴标准的 XYZ URL 模板并保存

URL 占位符支持

  • {z} : 缩放级别
  • {x} : 瓦片 X 坐标
  • {y} : 瓦片 Y 坐标
  • {quadkey} : Bing 风格四叉树键值

🌍 Custom Data Sources

Advanced: Adding third-party tile services

⚠️ License Warning: Ensure you have the right to use the data sources you add.

How to Add

  1. Go to App Settings → Data Sources
  2. Select Custom Tile Source under Satellite Imagery
  3. Paste a standard XYZ URL template and save

Supported Placeholders

  • {z} : Zoom Level
  • {x} : Tile X Coordinate
  • {y} : Tile Y Coordinate
  • {quadkey} : Bing-style Quadkey
