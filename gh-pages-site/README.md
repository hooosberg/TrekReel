### About

**TrekReel** is a local-first 3D storytelling app built for hikers, runners, and cyclists. Import GPX tracks and create cinematic route videos instantly, no cloud required.

### ✨ Highlights

#### 1. As Simple as a Map PPT
Auto-generate 3D terrain from GPX. Draw routes manually or import to visualize plans instantly.

![Route Animation](./img/feature_route.png)

#### 2. Rich Annotations
Add markers at key spots. Visualize camps, water sources, and risks with terrain context.

![Rich Annotations](./img/feature_marker.png)

### 🚀 Key Features

| Feature | Description |
| --- | --- |
| 📥 **Import Tracks** | Drag and drop `GPX`, `KML`, or `KMZ` files |
| 🏔️ **3D Terrain** | Real elevation data with satellite/outdoor map overlays |
| 🎬 **Cinematic Camera** | Smooth camera interpolation with keyframe system |
| 📍 **Rich Annotations** | Add markers, photos, and notes at key spots |
| 🎥 **Video Export** | Generate route movies in multiple resolutions |
| 🔒 **Privacy First** | All data stays on your device, offline-ready |
