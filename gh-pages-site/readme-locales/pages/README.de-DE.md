### About

Gebaut für Wanderer, Läufer und Radfahrer. Importieren Sie GPX und erstellen Sie sofort filmische 3D-Videos.

### ✨ Highlights

#### 1. So einfach wie eine Karten-PPT
Generieren Sie automatisch 3D-Gelände aus GPX. Zeichnen Sie Routen manuell oder importieren Sie sie, um Pläne sofort zu visualisieren.

![Route Animation](../../img/feature_route.png)

#### 2. Umfangreiche Anmerkungen
Fügen Sie Markierungen an wichtigen Stellen hinzu. Visualisieren Sie Lager, Wasserquellen und Risiken im Geländekontext.

![Rich Annotations](../../img/feature_marker.png)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **3D-Gelände Viz** | Echte Höhendaten treffen auf Satellitenbilder. Visualisieren Sie Ihren Weg mit Tiefe. |
| 📍 **Routen-Storytelling** | Mehr als Wiedergabe. Fügen Sie Keyframes, Fotomarkierungen und Notizen hinzu, um die Geschichte zu erzählen. |
| 🎬 **Filmkamera** | Reibungslose Kamerainterpolationstools lassen Ihre Routenvideos wie Filme aussehen. |
| 🔒 **Datenschutz geht vor, Offline-fähig** |  |
