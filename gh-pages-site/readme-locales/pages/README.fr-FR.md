### About

Conçu pour les randonneurs, les coureurs et les cyclistes. Importez GPX, créez instantanément des vidéos cinématographiques 3D.

### ✨ Highlights

#### 1. Aussi simple qu'une carte PPT
Générez automatiquement un terrain 3D à partir de GPX. Dessinez des itinéraires manuellement ou importez-les pour visualiser instantanément les plans.

![Route Animation](../../img/feature_route.png)

#### 2. Annotations riches
Ajoutez des marqueurs aux endroits clés. Visualisez les camps, les sources d'eau et les risques avec le contexte du terrain.

![Rich Annotations](../../img/feature_marker.png)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **Visualisation du terrain 3D** | Les données d'altitude réelles rencontrent l'imagerie satellite. visualisez votre chemin avec profondeur. |
| 📍 **Conte d'itinéraire** | Plus que la lecture. Ajoutez des images clés, des marqueurs photo et des notes pour raconter l'histoire. |
| 🎬 **Caméra cinématique** | Les outils d'interpolation fluides de la caméra donnent à vos vidéos d'itinéraire l'apparence de films. |
| 🔒 **La confidentialité d'abord, prêt hors ligne** |  |
