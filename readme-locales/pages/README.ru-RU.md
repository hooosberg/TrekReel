### About

Создан для туристов, бегунов и велосипедистов. Импортируйте GPX и мгновенно создавайте кинематографические 3D-видео.

### ✨ Highlights

#### 1. Просто как карта PPT
Автоматическое создание 3D-ландшафта из GPX. Рисуйте маршруты вручную или импортируйте их для мгновенной визуализации планов.

![Route Animation](../../img/feature_route.png)

#### 2. Богатые аннотации
Добавьте маркеры в ключевых точках. Визуализируйте лагеря, источники воды и риски в контексте местности.

![Rich Annotations](../../img/feature_marker.png)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **3D визуализация местности** | Реальные данные о высоте соответствуют спутниковым изображениям. визуализируйте свой путь с глубиной. |
| 📍 **Рассказ о маршруте** | Больше, чем воспроизведение. Добавляйте ключевые кадры, фотомаркеры и заметки, чтобы рассказать историю. |
| 🎬 **Кинематографическая камера** | Плавные инструменты интерполяции камеры делают видео маршрутов похожими на фильмы. |
| 🔒 **Конфиденциальность прежде всего, готовность к работе в автономном режиме** |  |
