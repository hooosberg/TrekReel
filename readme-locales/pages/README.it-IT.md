### About

Costruito per escursionisti, corridori e ciclisti. Importa GPX, crea istantaneamente video 3D cinematografici.

### ✨ Highlights

#### 1. Semplice come una mappa PPT
Genera automaticamente terreno 3D da GPX. Disegna manualmente i percorsi o importali per visualizzare immediatamente i piani.

![Route Animation](../../img/feature_route.png)

#### 2. Annotazioni ricche
Aggiungi marcatori nei punti chiave. Visualizza accampamenti, fonti d'acqua e rischi con il contesto del terreno.

![Rich Annotations](../../img/feature_marker.png)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **Visualizzazione del terreno 3D** | I dati di elevazione reale incontrano le immagini satellitari. visualizza il tuo percorso con profondità. |
| 📍 **Itinerario narrativo** | Più che riproduzione. Aggiungi fotogrammi chiave, marcatori fotografici e note per raccontare la storia. |
| 🎬 **Telecamera cinematografica** | Gli strumenti di interpolazione della fotocamera fluidi fanno sì che i video del tuo percorso sembrino film. |
| 🔒 **La privacy prima di tutto, pronto offline** |  |
