### About

पैदल यात्रियों, धावकों और साइकिल चालकों के लिए बनाया गया। जीपीएक्स आयात करें, तुरंत सिनेमाई 3डी वीडियो बनाएं।

### ✨ Highlights

#### 1. मानचित्र पीपीटी जितना सरल
जीपीएक्स से 3डी भूभाग स्वतः उत्पन्न करें। योजनाओं को तुरंत देखने के लिए मैन्युअल रूप से मार्ग बनाएं या आयात करें।

![Route Animation](../../img/feature_route.png)

#### 2. Rich Annotations


![Rich Annotations](../../img/feature_marker.png)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **3डी भू-भाग अर्थात** | वास्तविक उन्नयन डेटा उपग्रह इमेजरी से मिलता है। अपने पथ की गहराई से कल्पना करें। |
| 📍 **रूट स्टोरीटेलिंग** | प्लेबैक से भी अधिक. कहानी बताने के लिए कीफ़्रेम, फ़ोटो मार्कर और नोट्स जोड़ें। |
| 🎬 **सिनेमाई कैमरा** | स्मूथ कैमरा इंटरपोलेशन टूल आपके रूट वीडियो को फिल्मों की तरह बनाते हैं। |
| 🔒 **गोपनीयता पहले, ऑफ़लाइन तैयार** |  |
