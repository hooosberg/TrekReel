### About

등산객, 달리기 선수, 자전거 타는 사람을 위해 제작되었습니다. GPX를 가져와서 영화 같은 3D 비디오를 즉시 제작하세요.

### ✨ Highlights

#### 1. 지도처럼 간단한 PPT
GPX에서 3D 지형을 자동 생성합니다. 경로를 수동으로 그리거나 가져와서 즉시 계획을 시각화할 수 있습니다.

![Route Animation](../../img/feature_route.jpg)

#### 2. 풍부한 주석
주요 지점에 마커를 추가하세요. 지형 상황에 따라 캠프, 수자원 및 위험을 시각화합니다.

![Rich Annotations](../../img/feature_marker.jpg)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **3D 지형 시각화** | 실제 고도 데이터와 위성 이미지가 만났습니다. 당신의 길을 깊이있게 시각화하십시오. |
| 📍 **루트 스토리텔링** | 재생 그 이상. 스토리를 전달하려면 키프레임, 사진 마커, 메모를 추가하세요. |
| 🎬 **시네마틱 카메라** | 부드러운 카메라 보간 도구를 사용하면 경로 비디오를 영화처럼 보이게 할 수 있습니다. |
| 🔒 **개인 정보 보호 우선, 오프라인 준비** |  |
