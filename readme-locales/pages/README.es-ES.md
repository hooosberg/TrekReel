### About

Diseñado para excursionistas, corredores y ciclistas. Importe GPX, cree videos cinematográficos en 3D al instante.

### ✨ Highlights

#### 1. Tan simple como un mapa PPT
Genera automáticamente terreno 3D desde GPX. Dibuja rutas manualmente o impórtalas para visualizar planos al instante.

![Route Animation](../../img/feature_route.jpg)

#### 2. Anotaciones ricas
Agregue marcadores en puntos clave. Visualice campamentos, fuentes de agua y riesgos con el contexto del terreno.

![Rich Annotations](../../img/feature_marker.jpg)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **Visualización del terreno 3D** | Los datos de elevación reales se combinan con imágenes de satélite. Visualiza tu camino con profundidad. |
| 📍 **Ruta Cuentacuentos** | Más que reproducción. Agregue fotogramas clave, marcadores de fotografías y notas para contar la historia. |
| 🎬 **cámara cinematográfica** | Las suaves herramientas de interpolación de cámaras hacen que sus videos de ruta parezcan películas. |
| 🔒 **Privacidad primero, listo sin conexión** |  |
