### About

مصممة للمتنزهين والعدائين وراكبي الدراجات. قم باستيراد GPX وإنشاء مقاطع فيديو سينمائية ثلاثية الأبعاد على الفور.

### ✨ Highlights

#### 1. بسيطة مثل خريطة PPT
إنشاء تضاريس ثلاثية الأبعاد تلقائيًا من GPX. ارسم المسارات يدويًا أو قم باستيرادها لتصور الخطط على الفور.

![Route Animation](../../img/feature_route.jpg)

#### 2. التعليقات التوضيحية الغنية
أضف علامات في النقاط الرئيسية. تصور المخيمات ومصادر المياه والمخاطر مع سياق التضاريس.

![Rich Annotations](../../img/feature_marker.jpg)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **3D التضاريس بمعنى** | تتوافق بيانات الارتفاع الحقيقية مع صور الأقمار الصناعية. تصور طريقك بعمق. |
| 📍 **رواية الطريق** | أكثر من التشغيل. أضف الإطارات الرئيسية وعلامات الصور والملاحظات لتحكي القصة. |
| 🎬 **الكاميرا السينمائية** | أدوات الاستيفاء السلسة للكاميرا تجعل مقاطع فيديو مسارك تبدو وكأنها أفلام. |
| 🔒 **الخصوصية أولاً، جاهز للاستخدام دون اتصال بالإنترنت** |  |
