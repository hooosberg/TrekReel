### About

ハイカー、ランナー、サイクリストのために作られています。 GPX をインポートし、映画のような 3D ビデオを即座に作成します。

### ✨ Highlights

#### 1. 地図のようなシンプルな PPT
GPX から 3D 地形を自動生成します。ルートを手動で描画するか、インポートして計画を即座に視覚化します。

![Route Animation](../../img/feature_route.png)

#### 2. 豊富な注釈
重要な場所にマーカーを追加します。地形のコンテキストを使用してキャンプ、水源、リスクを視覚化します。

![Rich Annotations](../../img/feature_marker.png)

### 🚀 Features

| | |
| --- | --- |
| 🏔️ **3D 地形 Viz** | 実際の標高データと衛星画像が融合します。自分の進む道を奥行きをもって視覚化します。 |
| 📍 **ルートストーリーテリング** | 再生以上のもの。キーフレーム、写真マーカー、メモを追加してストーリーを伝えます。 |
| 🎬 **映画用カメラ** | スムーズなカメラ補間ツールにより、ルートビデオが映画のように見えます。 |
| 🔒 **プライバシー第一、オフライン対応** |  |
